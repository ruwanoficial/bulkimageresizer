# 🖼️ Bulk Image Resizer & Compressor (EvoLabs)

An ultra-simple Windows tool to **bulk resize and compress images** with just a few clicks — no installation or Python required.

---

## 📦 Features

- ✅ **Batch compress** images under 1MB without noticeable quality loss
- ✅ Supports **JPEG**, **PNG**, and **WEBP** formats
- ✅ Option to **resize large images**
- ✅ Easy-to-use **graphical interface (GUI)**
- ✅ Works offline — just download and run

---

## 🖥️ Download

👉 **[Download .EXE (Windows 64-bit)](https://github.com/ruwanoficial/bulkimageresizer/releases/download/V1.0.0/imageresizer.exe)**  
_No installation required. Compatible with Windows 10/11 (64-bit)._

---

## 🚀 How to Use

1. **Run** `imageresizer.exe` (no need to install).
2. Click **"Select Folder"** to pick the folder containing your images.
3. Choose your **output format** (JPEG / PNG / WEBP).
4. Click **"Start Compression"**.
5. Compressed images will be saved in a new folder called `/compressed`.

---

## 📂 Supported Formats

- `.jpg`, `.jpeg`
- `.png`
- `.webp`

---

## 💡 Tips

- Ideal for photographers, designers, and web developers.
- Works best with images smaller than `8000x8000` pixels.
- Automatically targets compressed file size under **1MB** while retaining visual quality.
